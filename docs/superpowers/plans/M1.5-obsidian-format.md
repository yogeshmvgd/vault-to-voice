# M1.5 Obsidian Daily-Notes Format Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read a real Obsidian vault made of daily notes (`Daily/DD-MM-YYYY.md`, sections `## Games/Books/Movies`, bullets linking `[[Work]]`) plus one page per work, turn every linked bullet into a dated per-work `Note`, and detect two kinds of post ideas: per-work (stable ids) and cross-work themes.

**Architecture:** A new `ObsidianVaultReader` implements the existing `VaultReader` protocol, so chunking, embeddings, FAISS, opinion scoring and the M2 graph keep consuming `Note`s unchanged. `Note` and the manifest gain `work_id` and `links`. Idea detection groups notes by `work_id` for work ideas and clusters work-level vectors for theme ideas. `VAULT_FORMAT=flat` keeps the M1 reader.

**Tech Stack:** Python 3.11, pydantic v2, python-frontmatter, re, numpy, scikit-learn, Typer, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-obsidian-daily-notes-design.md` (extends `2026-10-10-vault-to-voice-design.md`).

**Session:** one session (S5a) on branch `m2-post-graph`, before the M2 plan's Task 1. End per `CLAUDE.md` protocol.

## Review Focus

1. Real-world daily-note markdown: tabs vs spaces for nested bullets, `*`/`+`/`1.` markers, blank lines inside a list, Windows CRLF line endings → entries split the same way. Pinned in Task 3.
2. Link syntax variety: `[[A|alias]]`, `[[A#h]]`, `[[Folder/A]]`, `[[A.md]]`, embeds `![[x.png]]`, links inside inline code, differently-cased links to the same page → same `work_id`, embeds/code ignored. Pinned in Tasks 2–3.
3. Editing one bullet in today's note → only that entry is re-embedded and re-scored; other entries of the same file are unchanged. Pinned in Task 3 (hash) and Task 1 (ingest).
4. Upgrading an existing `data/manifest.db` from M1 (no `work_id` column) → opens without error and forces one full rebuild. Pinned in Task 1.
5. A work idea that gains entries day by day keeps the same `idea_id`, title and status (`done` stays `done`) with no new LLM label call. Pinned in Task 4.

```python
import hashlib
import re

from vault_to_voice.vault.reader import slugify

WIKILINK = re.compile(r"(!?)\[\[([^\[\]]+?)\]\]")
INLINE_CODE = re.compile(r"`[^`\n]*`")


def parse_link(inner: str) -> tuple[str, str]:
    """'Folder/Target#heading|alias' -> ('Target', 'alias' or 'Target')."""
    target_part, _, alias = inner.partition("|")
    target = target_part.split("#", 1)[0].strip().rsplit("/", 1)[-1].strip()
    if target.lower().endswith(".md"):
        target = target[:-3]
    return target, alias.strip() or target


def find_links(text: str) -> list[str]:
    targets = []
    for m in WIKILINK.finditer(INLINE_CODE.sub("", text)):
        target, _ = parse_link(m.group(2))
        if not m.group(1) and target:
            targets.append(target)
    return targets


def render_links(text: str) -> str:
    return WIKILINK.sub(lambda m: "" if m.group(1) else parse_link(m.group(2))[1], text)


def work_id_for(target: str) -> str:
    return slugify(target) or "work-" + hashlib.sha1(target.encode()).hexdigest()[:10]
```

```python
_NOTE_TYPES = {"game", "book", "movie", "other"}


def _parse_categories(raw: str) -> dict[str, str]:
    out = {}
    for pair in filter(None, (p.strip() for p in raw.split(","))):
        heading, _, note_type = pair.partition("=")
        note_type = note_type.strip().lower()
        if note_type not in _NOTE_TYPES:
            raise ValueError(f"category heading {heading!r} maps to unknown type {note_type!r}")
        out[heading.strip().lower()] = note_type
    return out
```

```python
import datetime as dt
import hashlib
import re
from collections.abc import Iterator
from dataclasses import dataclass
from pathlib import Path
from typing import get_args

import frontmatter
import structlog

from vault_to_voice.vault.links import find_links, render_links, work_id_for
from vault_to_voice.vault.models import Note, NoteType
from vault_to_voice.vault.reader import _parse_date, _path_id

log = structlog.get_logger()

DEFAULT_CATEGORIES = {"games": "game", "books": "book", "movies": "movie"}
_HEADING = re.compile(r"^(#{1,6})\s+(.*?)\s*#*\s*$")
_BULLET = re.compile(r"^(?:[-*+]|\d+[.)])\s+(.*)$")
_NESTED_MARKER = re.compile(r"^(?:[-*+]|\d+[.)])\s+")


@dataclass
class ReadStats:
    daily_files: int = 0
    entries: int = 0
    pages: int = 0
    unlinked_skipped: int = 0
    empty_skipped: int = 0


def split_entries(body: str, categories: dict[str, str]) -> list[tuple[str, str]]:
    """(note_type, raw entry text) per top-level bullet inside a category section."""
    entries: list[tuple[str, str]] = []
    current: str | None = None
    buf: list[str] | None = None
    blank_seen = False

    def flush() -> None:
        if buf is not None and current is not None:
            entries.append((current, "\n".join(buf).strip()))

    for line in body.splitlines():
        heading = _HEADING.match(line)
        if heading:
            flush()
            buf = None
            current = categories.get(heading.group(2).strip().lower())
            continue
        if current is None:
            continue
        bullet = _BULLET.match(line)
        if bullet:
            flush()
            buf, blank_seen = [bullet.group(1).strip()], False
        elif buf is None:
            continue
        elif not line.strip():
            blank_seen = True
        elif line[0] in " \t":
            buf.append(_NESTED_MARKER.sub("", line.strip()))
            blank_seen = False
        elif blank_seen:  # an unindented paragraph after a blank line ends the list
            flush()
            buf = None
        else:  # lazy continuation line
            buf.append(line.strip())
    flush()
    return entries


class ObsidianVaultReader:
    def __init__(
        self,
        root: Path,
        *,
        daily_folder: str = "Daily",
        date_format: str = "%d-%m-%Y",
        categories: dict[str, str] | None = None,
    ):
        self.root = Path(root)
        self.daily_folder = daily_folder.lower()
        self.date_format = date_format
        self.categories = categories or DEFAULT_CATEGORIES
        self.stats = ReadStats()

    def iter_notes(self) -> Iterator[Note]:
        if not self.root.is_dir():
            raise FileNotFoundError(f"Vault not found: {self.root}")
        self.stats = ReadStats()
        paths = [
            p for p in sorted(self.root.rglob("*.md"))
            if not any(part.startswith(".") for part in p.relative_to(self.root).parts)
        ]
        titles = {p.stem.lower(): p.stem for p in paths}
        seen: set[str] = set()
        for path in paths:
            rel = path.relative_to(self.root)
            day = self._daily_date(rel)
            notes = self._daily(path, rel, day, titles) if day else self._page(path, rel)
            for note in notes:
                if note.id in seen:  # e.g. two pages with the same name in different folders
                    note = note.model_copy(update={"id": _path_id(rel)})
                seen.add(note.id)
                yield note

    def _daily_date(self, rel: Path) -> dt.date | None:
        if len(rel.parts) < 2 or rel.parts[0].lower() != self.daily_folder:
            return None
        try:
            return dt.datetime.strptime(rel.stem, self.date_format).date()
        except ValueError:
            log.warning("daily_note_bad_name", path=rel.as_posix(), format=self.date_format)
            return None

    def _load(self, path: Path, rel: Path) -> tuple[str, frontmatter.Post] | None:
        raw = path.read_bytes().decode("utf-8", errors="replace")
        try:
            return raw, frontmatter.loads(raw)
        except Exception as exc:  # malformed YAML must not crash ingest
            log.warning("bad_frontmatter", path=rel.as_posix(), error=str(exc))
            return None

    def _daily(self, path: Path, rel: Path, day: dt.date, titles: dict[str, str]) -> list[Note]:
        loaded = self._load(path, rel)
        if loaded is None:
            return []
        self.stats.daily_files += 1
        notes: list[Note] = []
        per_work: dict[str, int] = {}
        for note_type, text in split_entries(loaded[1].content, self.categories):
            targets = find_links(text)
            if not targets:
                self.stats.unlinked_skipped += 1
                continue
            body = render_links(text).strip()
            if not re.search(r"\w", render_links(re.sub(r"\[\[[^\]]*\]\]", "", text))):
                self.stats.empty_skipped += 1
                continue
            work_id = work_id_for(targets[0])
            per_work[work_id] = per_work.get(work_id, 0) + 1
            suffix = "" if per_work[work_id] == 1 else f"-{per_work[work_id]}"
            notes.append(
                Note(
                    id=f"{work_id}@{day.isoformat()}{suffix}",
                    title=titles.get(targets[0].lower(), targets[0]),
                    type=note_type,
                    date=day,
                    body=body,
                    path=rel.as_posix(),
                    hash=hashlib.sha256(f"{note_type}\n{body}".encode()).hexdigest(),
                    work_id=work_id,
                    links=tuple(dict.fromkeys(work_id_for(t) for t in targets)),
                )
            )
        self.stats.entries += len(notes)
        return notes

    def _page(self, path: Path, rel: Path) -> list[Note]:
        loaded = self._load(path, rel)
        if loaded is None:
            return []
        raw, post = loaded
        content = post.content.strip()
        if not any(ln.strip() and not _HEADING.match(ln) for ln in content.splitlines()):
            self.stats.empty_skipped += 1
            return []
        meta = post.metadata
        note_type = str(meta.get("type", "")).lower()
        if note_type not in get_args(NoteType):
            folder = rel.parts[0].lower() if len(rel.parts) > 1 else ""
            note_type = self.categories.get(folder, "other")
        work_id = work_id_for(path.stem)
        self.stats.pages += 1
        return [
            Note(
                id=str(meta.get("id") or work_id),
                title=str(meta.get("title") or path.stem),
                type=note_type,
                date=_parse_date(meta.get("date")),
                body=render_links(content).strip(),
                path=rel.as_posix(),
                hash=hashlib.sha256(raw.encode("utf-8")).hexdigest(),
                work_id=work_id,
                links=tuple(dict.fromkeys(work_id_for(t) for t in find_links(content))),
            )
        ]
```

```python
class Idea(BaseModel):
    idea_id: str
    title: str
    angle: str
    theme: str
    note_ids: list[str]
    opinion_score: float
    status: Literal["new", "done"] = "new"
    kind: Literal["work", "theme"] = "theme"
    work_ids: list[str] = Field(default_factory=list)


def make_idea_id(ids: list[str]) -> str:
    return "idea_" + hashlib.sha1(",".join(sorted(ids)).encode()).hexdigest()[:10]


def work_idea_id(work_id: str) -> str:
    return f"idea_work_{work_id}"


def detect_ideas(
    manifest: Manifest,
    store: FaissStore,
    llm: LLMClient,
    *,
    min_notes: int,
    min_opinionated: int,
    opinion_threshold: float,
    seed: int,
) -> list[Idea]:
    if len(store) != manifest.chunk_count() or manifest.get_meta("dirty") == "1":
        raise IndexOutOfSyncError(
            "Vector index is missing or out of sync with the manifest "
            "(e.g. EMBEDDING_PROVIDER changed). Run `v2v ingest` first."
        )
    note_ids, vectors = note_embeddings(manifest, store)
    if not note_ids:
        manifest.save_ideas([])
        return []
    rows = {r.note_id: r for r in manifest.notes()}
    existing = {i.idea_id: i for i in manifest.list_ideas()}
    vector_of = dict(zip(note_ids, vectors, strict=True))

    groups: dict[str, list[str]] = defaultdict(list)
    for nid in note_ids:
        groups[rows[nid].work_id or nid].append(nid)

    def qualifies(members: list[str]) -> bool:
        scores = [rows[n].opinion_score or 0.0 for n in members]
        return len(members) >= min_notes and (
            sum(s >= opinion_threshold for s in scores) >= min_opinionated
        )

    def make(idea_id: str, kind: str, works: list[str], members: list[str]) -> Idea:
        score = round(mean(rows[n].opinion_score or 0.0 for n in members), 3)
        if idea_id in existing:  # keep title/angle/status; refresh membership
            return existing[idea_id].model_copy(
                update={"note_ids": members, "work_ids": works, "opinion_score": score}
            )
        lab = label_cluster(llm, [rows[n] for n in members], kind=kind)
        return Idea(idea_id=idea_id, title=lab.title, angle=lab.angle, theme=lab.theme,
                    note_ids=members, opinion_score=score, kind=kind, work_ids=works)

    ideas: list[Idea] = []
    for work, members in sorted(groups.items()):
        members = sorted(members)
        if qualifies(members):
            ideas.append(make(work_idea_id(work), "work", [work], members))

    works = sorted(groups)
    work_vectors = np.vstack([np.mean([vector_of[n] for n in groups[w]], axis=0) for w in works])
    norms = np.linalg.norm(work_vectors, axis=1, keepdims=True)
    work_vectors = work_vectors / np.where(norms == 0, 1.0, norms)
    labels = cluster(work_vectors.astype(np.float32), seed=seed)
    for label in sorted(set(labels.tolist())):
        members_works = [w for w, lab in zip(works, labels, strict=True) if lab == label]
        if len(members_works) < 2:
            continue
        members = sorted(n for w in members_works for n in groups[w])
        if qualifies(members):
            ideas.append(make(make_idea_id(members_works), "theme", members_works, members))

    manifest.save_ideas(ideas)
    return ideas
```

`docs/obsidian-setup.md`:
````markdown
# Setting up your Obsidian vault for vault-to-voice

vault-to-voice reads **daily notes** split into category sections, where each bullet links the
game, book or movie it is about. It never modifies your vault.

## 1. Folder layout
```
YourVault/
├─ Daily/        one note per day, named DD-MM-YYYY.md (e.g. 10-10-2026.md)
├─ Games/        one page per game   (Witcher 3.md)
├─ Books/        one page per book   (Dune.md)
├─ Movies/       one page per movie
└─ Templates/    Daily.md (the template below)
```

## 2. The daily template
Create `Templates/Daily.md`:
```markdown
---
date: {{date:DD-MM-YYYY}}
---
## Games
- 

## Books
- 

## Movies
- 

## Other
- 
```
`## Other` is for everything else in your day — vault-to-voice ignores it.

## 3. Obsidian settings (click by click)
1. **Settings → Core plugins** → turn on **Daily notes** and **Templates**.
2. **Settings → Templates** → *Template folder location* = `Templates`.
3. **Settings → Daily notes**:
   - *Date format* = `DD-MM-YYYY`
   - *New file location* = `Daily`
   - *Template file location* = `Templates/Daily`
4. Click the calendar icon in the left ribbon (or run "Open today's daily note") — today's note
   opens pre-filled.

## 4. Writing an entry
- One bullet per thing you played/read/watched: `- Played [[Witcher 3]] — the Bloody Baron …`
- Type `[[` and start the title; Obsidian autocompletes existing pages.
- Indented sub-bullets belong to the bullet above them.
- A bullet without a `[[link]]` is skipped (the ingest report counts these).
- Linking two works in one bullet is fine; it is filed under the first link.
- New work? Click the link once to create the page, then move it into `Games/`, `Books/` or
  `Movies/`. Add a few lines there when you have a settled opinion.

## 5. Point vault-to-voice at your vault
In `.env` (outside the repo — the tool refuses vault paths inside it):
```dotenv
VAULT_PATH=C:/Users/you/Documents/MyVault
VAULT_FORMAT=obsidian
DAILY_FOLDER=Daily
DAILY_DATE_FORMAT=%d-%m-%Y
CATEGORY_HEADINGS=games=game,books=book,movies=movie
```
Then: `uv run v2v ingest`, `uv run v2v style`, `uv run v2v ideas`.
````
